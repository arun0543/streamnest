Built-in Network File Sharing (FTP / Network Drive)

Status: ● Active on port 2121
StreamNest has a built-in network file server running directly inside Node.js. Other computers, phones, and VLC can connect directly over Wi-Fi without needing Samba installed!
Addresses: ftp://192.168.0.222:2121 or ftp://192.168.31.84:2121
Username: streamnest
Password: 123
Windows Explorer: Open This PC > Right-click > Add a network location > enter ftp://192.168.0.222:2121
VLC / Mobile File Manager: Select FTP / Network > connect with the credentials above.

Storage backend

Active backend: loading…
Set the STREAMNEST_DB environment variable before starting the server:
STREAMNEST_DB=file — default — JSON files in data/
STREAMNEST_DB=sqlite — SQLite at data/streamnest.db
STREAMNEST_DB=sqlite:./custom.db — SQLite custom path
STREAMNEST_DB=postgres://user:pass@localhost/dbname — PostgreSQL

Example: PORT=8090 STREAMNEST_DB=sqlite npm start

Native SMB client (SMB 2.0.2/2.1, NTLM). If your server needs SMB3 signing/encryption (Windows 11 24H2 defaults), use a UNC path or mount the share and add it as a Local folder instead. See docs/SMB.md.

Auto-detect: Leave Port blank for automatic (445). Host is auto-resolved via DNS. The connection is tested before adding.
